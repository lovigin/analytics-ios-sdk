# Публикация iOS SDK

Репозиторий: https://github.com/lovigin/analytics-ios-sdk

1. Помести содержимое папки `sdk-ios` в корень этого репозитория: `Package.swift`, `Sources`, `Tests`, `README.md`, `.gitignore`. Не загружай `.build` и `.swiftpm`.
2. Проверь пакет: `swift test`. Если iCloud мешает подписи тестов, используй `swift test --scratch-path /tmp/lovigin-ios-check`.
3. Закоммить и отправь изменения. Создай тег `0.1.0` и отправь его в GitHub:

```sh
git tag 0.1.0
git push origin 0.1.0
```

После этого пользователи смогут добавить URL репозитория в Xcode → File → Add Package Dependencies и выбрать версию 0.1.0. Для следующих выпусков нужны новые теги; опубликованные теги не переписывай.

## Обновление панели

Для плашки `+N` обнови и пересобери **backend и frontend**. Миграция базы не требуется. Backend возвращает дневные суммы за весь сохранённый период; frontend хранит предыдущий результат отдельно для аккаунта и проекта в браузере администратора.

На первом открытии сохраняется точка отсчёта. На следующих открытиях показывается положительный прирост. Смена периода 7/30/90 дней не меняет эту точку отсчёта в рамках открытой страницы. После очистки хранилища браузера или на другом устройстве отсчёт начинается заново. Это не хранение данных посетителей и не изменение SDK на клиентских сайтах.

iOS SDK использует существующий API агрегатов: просмотры экранов попадают в Page views и Top pages. Для приложения нужен отдельный проект с подтверждённым доменом/поддоменом и отдельным write-only токеном. Специальный тип проекта без домена в этом выпуске не добавлен.
